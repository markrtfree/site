超售与 AWS 积分耗尽？

【完全命中·核心根因】

老母鸡单实例超售标称带宽超 7.6G，大流量租户将 AWS Lightsail 的公网突发网络积分消耗殆尽。AWS 底层物理网关实施限流丢包惩罚，导致公网链路产生 31.6% 剧烈丢包。

为什么“内网互测跑满 647M”，而“公网回程只有 3.4M”？

AWS Lightsail（基于 EC2 T 系列架构）采用突发网络积分机制（Network Allowance）：

  • 同机房 VPC 内网流量：不经过 AWS 外网 NAT 网关，不扣减公网突发网络配额（Allowance），因此双鸡互测能够完全释放物理网卡能力，轻松达到 647 Mbps。
  • 出公网回程流量：必须经过 AWS 边缘 Internet Gateway。当超售宿主机的公网突发积分被耗尽后，AWS 边界交换机进行强制整形与惩罚性丢包（实测丢包率高达 31.6%）。TCP 协议检测到丢包后立即将拥塞窗口由数百收缩至 30，最终带宽暴跌至 3.40 Mbps。
